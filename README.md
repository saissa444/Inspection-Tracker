# 學生加扣分・獎懲登錄（合併版）

把「加扣分APP」和「獎懲紀錄產生器」合成一個 App。名冊與學校範本**只要匯入一次**，用開啟密碼加密後存在本機瀏覽器，不會上傳。

## 功能

- **兩個分頁**：加扣分、獎懲。兩邊的操作方式、選項、編輯與匯出格式都和原本的 App 相同。
- **多期別名冊**：每期各匯入一份名冊（例如第44期、第45期）。畫面上方切換「目前期別」，輸入隊號時只在該期名冊裡查找，不同期的女生隊號重複也不會混淆。預覽表有「期別」欄，兩期紀錄可匯出在同一份 Excel。
- **只匯入一次**：名冊、兩份範本，以及尚未清空的紀錄，都加密存在這台裝置的這個瀏覽器。下次開啟時輸入密碼就能直接使用。
- **開啟密碼（選用）**：預設不需要密碼，打開就能用；可在「名冊」設定密碼。設定後以 AES-GCM 256 加密，金鑰由密碼經 PBKDF2-SHA256（31 萬次）推導。密碼本身不會被儲存，**忘記密碼只能清除本機資料後重新匯入**。
- **鎖定**：右上角「鎖定」按鈕，加上閒置自動鎖定（預設 15 分鐘，可在設定裡調整）。
- **完全離線**：所有元件都放在專案內，不會連到外部網站；加入主畫面後沒有網路也能使用。

## 內務（本版新增）

「內務」分頁把查內務、扣分、統計放在同一個 App：

1. **登錄公告**：把 LINE 的內務檢查公告整則貼上，系統用目前期別的名冊辨識女生隊號、建制隊號和寢室，日期、括號註記、樓層公共區域都會自動判讀。
2. **轉入加扣分**：儲存時，每位同學的每一項個人優缺點會在「加扣分」分頁新增一筆 0.2 分的紀錄（優點加分、缺點扣分），之後照原本流程匯出學校 Excel。公區優缺點只算寢室統計。取代同一天的檢查時，之前轉入、還沒清空的紀錄會一起更新。事蹟說明在「寢室名單與設定」選一次即可。
3. **統計**：月統計（最劣寢、最優寢、負分／正分名單、複製到 LINE）、明細查詢（任意期間的寢室總覽、個人總覽、單一寢室或個人的逐筆明細，最好／最差自動標色）。
4. **寢室名單**：每一期一份，一行一間寢室。
5. **備份**：內務資料包含在 App「備份」分頁的全部資料備份裡（名冊、範本、加扣分、獎懲、內務一起備份）。

內務資料和名冊一樣加密存在這台裝置的瀏覽器。`.gitignore` 已排除內務資料檔，請勿提交到 GitHub。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的儲存庫（例如 `student-records`），把這個資料夾內的所有檔案上傳（包含 `vendor/`、`js/`、`icons/`）。
2. 到 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
3. 網址會是 `https://saissa444.github.io/student-records/`。
4. iPhone：用 Safari 開啟 → 分享 → 「加入主畫面」，之後從主畫面開啟。

> 必須用 https 網址開啟（GitHub Pages 就是），加密功能才能使用；直接雙擊本機的 index.html 在部分瀏覽器可能無法使用。

## 第一次使用

1. 設定開啟密碼。
2. 在「名冊」匯入每一期的名冊。系統會依建制隊號前兩碼自動建議期別名稱，例如 44xxxx 會建議「第44期」，名稱可以修改。
3. 匯入加扣分範本、獎懲範本，各一次。
4. 之後每次開啟只要輸入密碼。

換學期或名冊異動時，按該期的「更新名冊」覆蓋即可。

## 注意事項

- 資料只存在「這台裝置的這個瀏覽器」。辦公室電腦和 iPhone 要各自設定一次。清除瀏覽器網站資料後需要重新匯入。
- 同一個 github.io 網址底下的其他專案理論上可以讀到這個 App 的本機資料庫，但內容是加密的，沒有密碼無法解開。
- 加扣分匯出改用專案內附的 SheetJS，直接改寫範本中「工作表1」的資料列。範本的其他工作表、格式、下拉選單都會保留，開檔時 Excel 會自動重算「加扣分」欄。原本 App 需要從網路載入 xlsx-populate，現在不需要了。
- **禁止把真實名冊、匯出結果或含個資的截圖提交到 GitHub。** `.gitignore` 已排除 Excel 檔。

## 測試（全部使用虛構資料）

```sh
python3 test/make-fixtures.py            # 需要 openpyxl，產生虛構名冊與範本
python3 -m http.server 8765 &            # 在專案根目錄啟動本機伺服器
npm install playwright && node test/browser.e2e.js
```

測試涵蓋：設定密碼、匯入兩期名冊、錯誤檔案、重新整理後解鎖、兩期同女生隊號、跨期提示、批次新增與編輯、兩種匯出、鎖定、確認本機資料庫沒有明文、變更密碼、清除資料，並檢查沒有任何外部連線。

## 單機版（不需網路）

執行 `python3 tools/build-offline.py`，會在 `dist/` 產生 `學生加扣分獎懲_單機版.html`。所有程式都包在這一個檔案裡，在電腦上雙擊、用 Chrome 或 Edge 開啟就能使用，完全不需要網路。

- 資料一樣用開啟密碼加密，存在該瀏覽器裡。
- 建議把檔案放在固定的位置，並固定用同一個瀏覽器開啟。
- iPhone 無法直接開啟本機 HTML 程式，手機請用 GitHub Pages 版並「加入主畫面」，第一次開啟後也能離線使用。
